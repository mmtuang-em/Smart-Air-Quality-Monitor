An IoT-based air quality monitoring system using ESP8266, GP2Y1014 dust sensor, and OLED display.

## Project Overview

This project measures air quality using the GP2Y1014 dust sensor and displays the result on an OLED screen. Future versions will support Wi-Fi monitoring, data logging, and a custom 3D-printed enclosure.

## Hardware

- ESP8266 NodeMCU
- GP2Y1014 Dust Sensor
- OLED Display (I2C)
- Jumper Wires

## Software

- Arduino IDE
- Embedded C/C++
